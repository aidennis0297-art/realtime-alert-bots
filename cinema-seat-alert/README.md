# 🎬 메가박스 영화관 특별관 & 명당 잔여석 실시간 알리미

전국 114개 메가박스 극장의 실시간 상영시간표와 특별관(Dolby Cinema, Laser 등) 명당 잔여석을 감시하여 취소표 발생 시 **디스코드 3연속 버스트 푸시 알림(@everyone)**을 발송합니다.

---

## 🚀 주요 기능
1. **전국 114개 극장 8대 권역 필터링**: 서울, 경기, 인천, 대전/충청, 부산/경상, 광주/전라, 강원, 제주
2. **특별관 전용 필터링**: 돌비 시네마(Dolby Cinema), Dolby Atmos, Laser, Recliner 등
3. **명당 잔여석 실시간 감시**: 영화 제목 필터 및 최소 잔여석 기준 필터
4. **독립 웹 GUI 대시보드 (포트 8083)**: `run_gui.bat` 실행 시 브라우저 자동 실행

## ⚙️ 실행 방법
- **웹 대시보드 실행**: `run_gui.bat` 더블 클릭 (`http://localhost:8083`)
