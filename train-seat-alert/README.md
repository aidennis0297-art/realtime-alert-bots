# 🚄 KTX / SRT 열차 취소표 실시간 알리미

전국 33개 주요 KTX/SRT 정차역의 실시간 배차표와 취소표를 초 단위로 감시하고 잔여석 발생 시 **디스코드 3연속 버스트 푸시 알림(@everyone)**을 발송합니다.

---

## 🚀 주요 기능
1. **전국 33개 주요 정차역 5대 권역 필터링**: 서울/수도권, 대전/충청, 대구/경북, 부산/경남, 광주/전라
2. **SRT 모바일 NetFunnel 통신망 직통 연동**: 실시간 배차 및 취소표 조회
3. **일반실 & 특실/우등실 분리 감시**: 최소 좌석수 기준 지원
4. **독립 웹 GUI 대시보드 (포트 8082)**: `run_gui.bat` 실행 시 브라우저 자동 실행

## ⚙️ 실행 방법
- **웹 대시보드 실행**: `run_gui.bat` 더블 클릭 (`http://localhost:8082`)
