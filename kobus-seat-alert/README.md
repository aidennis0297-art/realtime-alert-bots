# 🚌 KOBUS 고속버스 실시간 잔여석 알리미 & 양방향 디스코드 챗봇

전국 224개 고속버스 터미널의 실시간 잔여 좌석을 초 단위로 감시하고 취소표 발생 시 **디스코드 3연속 버스트 푸시 알림(@everyone)** 및 **스마트폰 양방향 원격 제어**를 지원합니다.

---

## 🚀 주요 기능
1. **전국 224개 터미널 6대 권역 필터링**: 서울, 경기/인천, 강원, 대전/충청/세종, 광주/전라, 부산/대구/경상
2. **다인승 연석 설정 (`min_seats`)**: 1석, 2석, 3석, 4석 이상 옵션
3. **독립 웹 GUI 대시보드 (포트 8081)**: `run_gui.bat` 실행 시 브라우저 자동 실행
4. **스마트폰 양방향 챗봇 (`run_discord_bot.bat`)**:
   - `!버스`: 실시간 배차 즉시 조회
   - `!버스 서울 부산 20260925`: 노선 즉시 조회
   - `!버스 시작`, `!버스 중지`, `!버스 상태`, `!터미널 [검색어]`

## ⚙️ 실행 방법
- **웹 대시보드 실행**: `run_gui.bat` 더블 클릭 (`http://localhost:8081`)
- **디스코드 양방향 봇 실행**: `run_discord_bot.bat` 더블 클릭
