# 🎓 서울시립대학교(UOS) 수강신청 빈자리 실시간 알리미 & Web GUI 대시보드

서울시립대학교 수강신청 시스템(`sugang.uos.ac.kr`)의 3,000여 개 개설 교과목을 년도/학기/학과/이수구분/학년별로 자유롭게 검색하고, 원하는 과목을 **별표(⭐)**하여 실시간 빈자리 감지 및 **디스코드 3연타 모바일 푸시 알림**을 원클릭으로 제어할 수 있는 **Zero-dependency 로컬 웹 대시보드 시스템**입니다.

---

## 📌 주요 특징

1. **로컬 웹 GUI 대시보드 (Zero-dependency)**:
   - 외부 패키지 설치(`pip install`)가 필요 없는 순수 Python 표준 라이브러리(`http.server`, `urllib`, `threading`, `json`, `webbrowser`) 기반
   - 다크 테마의 직관적인 반응형 대시보드 제공
   - 더블 클릭 한 번으로 로컬 서버 실행 및 기본 웹 브라우저(`http://localhost:8080`) 자동 오픈
2. **년도 및 학기 동적 조회**:
   - 학년도(2026, 2025, 2024...) 및 학기(1학기, 2학기, 여름계절, 겨울계절) 선택 후 [🔄 과목 불러오기] 클릭 시 UOS 서버에서 실시간 3,000+건 개설 과목 수신
3. **다차원 스마트 필터 & 통합 검색**:
   - **학과/학부 필터**: 120여 개 개설 학과/학부 자동 추출 가나다순 필터링
   - **이수구분 필터**: 전공필수(전필), 전공선택(전선), 교양필수(교필), 교양선택(교선), 기초선택, 교직 등
   - **학년 필터**: 전체, 1학년, 2학년, 3학년, 4학년
   - **통합 검색창**: 과목명, 담당교수명, 과목번호(5자리) 키워드 즉시 검색
4. **관심 과목 별표(⭐) 및 실시간 감시 (Watchlist)**:
   - 테이블에서 과목별 ⭐ 클릭 시 "실시간 감시 대상 목록(Watchlist)"에 즉시 등록/해제
   - 별표된 과목들만 백그라운드 스레드에서 실시간 정원/신청인원 추적
   - `config.json`에 영구 저장되어 브라우저를 닫거나 재시작해도 유지
5. **디스코드 3연속 버스트 푸시 (@everyone)**:
   - 빈자리 발생 순간 놓치지 않도록 **1.5초 간격으로 3회 연속 모바일 푸시 알림** 발송
   - 스마트폰 잠금화면 진동/소리로 빠른 수강신청 대응 가능
6. **대시보드 내 원클릭 제어**:
   - 학번/비밀번호/디스코드 웹훅 설정 및 "로그인 검증", "디스코드 테스트 발송" 원클릭 테스트
   - 모니터링 [▶️ 시작] / [⏹️ 중지] 토글 스위치
   - 실시간 백그라운드 점검 로그 콘솔 스트리밍
7. **학칙 및 윤리 준수**:
   - 본 프로그램은 **'빈자리 감지 및 알림'** 기능만을 수행합니다.
   - 대학 학칙 및 수강신청 윤리 규정을 준수하기 위해 **자동 수강신청(매크로 신청) 기능은 포함하지 않습니다.**

## 🚀 실행 방법

### 방법 1. 웹 GUI 대시보드 실행 (강력 추천 ⭐)
- `run_gui.bat` 파일을 더블 클릭합니다.
- 또는 콘솔에서:
  ```bash
  python uos_web_server.py
  ```
- 웹 브라우저가 자동으로 실행되며 `http://localhost:8080` 대시보드가 열립니다.

### 방법 2. 콘솔 CLI 단독 실행
- 기존처럼 콘솔에서 직접 모니터링을 구동할 수도 있습니다:
  - `run_sugang_alert.bat` 더블 클릭
  - 또는: `python uos_sugang_alert.py`

## 🎮 디스코드 웹훅 연동 방법
1. 디스코드에서 알림을 받을 채널 접속 ➔ 채널 설정 ➔ 연동 ➔ 웹훅 만들기 ➔ **웹훅 URL 복사**
2. 웹 대시보드 우측 상단 [⚙️ 설정] 클릭 후 웹훅 URL 입력
3. [🔔 테스트 발송] 버튼을 눌러 모바일 디스코드 앱으로 정상 수신되는지 확인!
